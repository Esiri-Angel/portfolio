## Featured projects

## How the site is built

- `index.html` contains the page structure, project descriptions, and contact links.
- `style.css` defines the responsive royal-blue design.
- `main.js` draws the interactive particle sculpture and sample energy signal with Canvas and highlights the active navigation section.

## Run locally

Clone or download the repository and open `index.html` in a browser. GitHub Pages publishes the site from the root of `main`.
